# File/content policy

Проверка выполняется до извлечения/обработки: нормализованное имя, запрет `..`, allow-list расширений и лимит размера. Для реального production дополнительно нужны MIME/magic inspection, антивирус/песочница для недоверенных документов и отдельное хранилище без права исполнения.
