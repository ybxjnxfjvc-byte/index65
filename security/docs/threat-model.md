# Mini threat model — index65

## Scope

Публичный учебный кейс `ANGIOPHARM — система обучения`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Безопасная обработка файлов / архивов / контента

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Path traversal | Имя файла содержит ../ | basename + запрет traversal |
| T2 | Zip Slip | Архив содержит ../ при распаковке | Проверка каждого member до extract |
| T3 | Подмена типа | Расширение не соответствует сигнатуре | Allow-list + magic/header check |
| T4 | Слишком большой файл | Загрузка истощает ресурсы | Size limit до обработки |
| T5 | Активный контент | Публикуется неожиданный скрипт/ярлык | Предпубликационный allow-list типов |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
